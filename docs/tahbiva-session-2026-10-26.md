## מה השתנה היום, לפי הסדר

1. **שאלות פרופיל בתוך תחביבה** — נוסף מסך "עליך": גיל (18–99), עיר, טלפון (🔒 רק מאצ׳ים רואים). שאלה אחת בכל מסך.
2. **"זה או זה"** — ניסינו להוסיף הסבר למשמעות ("ככה אדע מה להציע לך"). המשתמש/ת אמר/ה שזה לא ברור → **הוחזר למקור**. המשמעות בפועל: לא נשמר בפרופיל, רק קובע את סדר הקטגוריות ואילו תחביבים יוצעו בגילוי.
3. **חלון "מה מעניין אותך"** עבר כמה גרסאות:
   - א. פאנל שנפתח למטה → הוחלף בפתיחה ליד הקטגוריה (אקורדיון), 3 קטגוריות + "עוד קטגוריות ↻".
   - ב. כל קטגוריה כמסך נפרד עם מעבר, אריחי אימוג׳י גדולים.
   - ג. בוטל "עוד קטגוריות"; אחר כך: כל הקטגוריות בעמודים של 3 (3·3·2·2) עם "המשך".
   - ד. לפי מפרט שהודבק: שלב 1 כרטיסי קטגוריה, שלב 2 "בוא/י נרד לפרטים" בלשוניות.
   - ה. **הגרסה הנוכחית** (לפי אב-טיפוס HTML שהודבק, "כרטיסיות בחירה ממוקדות"): **שלב 1** — רשימת כרטיסים עם "+"/✓. **שלב 2** — כרטיס ממוקד אחד לכל קטגוריה שנבחרה ("קטגוריה X מתוך Y", "שינוי קטגוריות", חזרה/הבא, "סיום והצגת מאצ׳ים"). אריחי תחביבים 3 בשורה. נשמר מנגנון הלחיצות 💚 → 🚀 → ביטול (באב-טיפוס היה ✓ בלבד).
4. **טקסט חופשי "ספר/י קצת על עצמך"** — נוסף כשאלה ראשונה במסך "עליך" (לא חובה). דוגמה: "אוהב/ת לטייל בטבע ולצייר בצבעי מים. בא לי להכיר שותף/ה לציור".
5. **"הפרופיל שלי" בדמו** — סודר בכרטיסים: שם + גיל · עיר → ✍️ עליי (טקסט + מה מחפש/ת) → 💚 התחביבים שלי → הוספת תחביב.
6. **המלצות אסטרטגיות (מהדבקה)** שיושמו:
   - **ערך מיידי** — מסך "לידך 👀" עם 3 אנשים קרובים + מפגש מקומי, מיד אחרי בחירת התחביבים.
   - **מיקום מוקדם** — העיר עברה ממסך "עליך" למסך נפרד אחרי שלב 2 (בחירה מהירה: פרדס חנה-כרכור, תל אביב…).
   - **שוברי קרח** — כפתורי "☕ קפה?" / "🚶 הליכה?" בכרטיסי אנשים (גם בטאב האנשים בבית).
7. **פישוט אחרי משוב** (הגרסה הנוכחית):
   - סימון תחביבים = רק 💚 אוהב/ת (לחיצה = ✓, שוב = ביטול). "רוצה לנסות" בבחירה בלבל → הוסר. בהמשך הוסר מכל מקום (גם מכרטיסי הגילוי: 💚 הוסף לפרופיל / דלג).
   - בחירת התחביבים בסגנון "זה או זה": אריחים גדולים, 2 בשורה, אימוג׳י גדול.
   - "☕ קפה? / 🚶 הליכה?" הוסרו ("לא קשור") → "💬 שלח הודעה" שפותח הודעה מוכנה על תחביב משותף.
   - מסך תמונות אחרי ההרשמה: גלריה אחת (שלי + תחביבים, עד 6, הראשונה = פרופיל) + כפתור "אעלה תמונות אחר כך". בדמו — בזיכרון בלבד.
   - "זה או זה" מזהה תחביבים: כל תשובה מסמנת מראש 2 תחביבים + הקטגוריות שלהם, והמשתמש/ת רק מאשר/ת או משנה בשלבים 1–2.
8. **תיעוד** — נכתב `docs/tahbiva-onboarding.md` עם כל המסכים וההחלטות.
