## 🔴 דחוף — פרטיות ואבטחה

### 1. מספרי טלפון ופרטים אישיים חשופים לכל אחד
- חוקי Firestore מאפשרים `read: if true` על `users` — כל אחד עם מפתח ה-API (שגלוי בקוד) יכול לשלוף את כל
  המשתמשים כולל טלפונים ושם מלא, בלי התחברות. אומת בפועל ב-2026-10-23 דרך Firestore REST.
- סותר את ההבטחה בהרשמה ובמדיניות הפרטיות שהטלפון מוצג רק למאצ'ים → חשיפה לפי חוק הגנת הפרטיות.
- הסתרת שם המשפחה בממשק (displayName) היא קוסמטית בלבד — השם המלא עדיין במסמך.
- בנוסף, `renderCard` / כרטיסי מאצ'ים ב-`ui-render.js` מטמיעים את כל אובייקט המשתמש (כולל `fullName` ו-`phone`)
  כ-JSON בתוך `onclick="showProfileModal(...)"` — גלוי ב"הצג מקור". לתקן יחד עם 1+2: להעביר רק email ולשלוף מ-`allUsers`.

### 2. כל אחד יכול להתחזות לכל משתמש
- ה-OTP נוצר ונבדק בדפדפן (`auth.js`, sessionStorage), וה"סשן" הוא אובייקט ב-localStorage (`hobbyMatchUser`).
- צ'אטים פתוחים לקריאה/כתיבה לכולם (`chats/... allow read, write: if true`), וכך גם עריכה/מחיקה של כל פרופיל ולייק.

**פתרון:** מעבר ל-Firebase Auth אמיתי (Email Link sign-in + Google שכבר קיים), ואז חוקים מהודקים:
משתמש עורך רק את עצמו, צ'אט רק לשני המשתתפים, טלפון ושם מלא במסמך/תת-אוסף נפרד שקריא רק למאצ'ים.
השינוי הגדול ביותר ברשימה — לעשות לפני שמביאים עוד משתמשים.
