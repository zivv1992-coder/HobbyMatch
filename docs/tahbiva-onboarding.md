# תחביבה — תהליך ההרשמה (דמו)

קובץ הדמו: `tahbiva-demo.html` (עצמאי, בלי Firebase — הבחירות נשמרות רק ב-localStorage, מפתח `tahbivaDraft3`).

## עקרונות
- נקי ופשוט: אימוג׳י במקום איורים, משפט קצר אחד בכל מסך, כפתורים במקום הסברים.
- מעברים חלקים בין המסכים (החלקה + דהייה) — זה החלק ה"מלוטש" היחיד.
- ערך מיידי: מיד אחרי בחירת התחביבים רואים 2–3 אנשים קרובים, לפני ששואלים פרטים אישיים.
- קרוב לבית: המיקום נשאל מוקדם, וכל ההמלצות (אנשים, מפגשים) מוצגות לפי העיר.
- יצירת קשר פשוטה: "💬 שלח הודעה" עם הודעה מוכנה מראש על תחביב משותף.
- כפתור "חזרה" מבטל קודם את הצעד האחרון בתוך המסך.

| 15 | הצטרפת 🎉 | → מסך הבית |

## מסך הבית
טאבים: 📅 פעילויות (עם העיר) · 👥 לידך (אנשים + שלח הודעה) · 👤 הפרופיל שלי.

**הפרופיל שלי** — מסודר בכרטיסים:
1. תמונה + שם + גיל · עיר
2. ✍️ עליי — הטקסט החופשי + מה אני מחפש/ת
3. 📸 תמונות — תמונות התחביבים + "הוספה"
4. 💚 התחביבים שלי — מה שסימנתי "אוהב/ת"
5. + הוספת תחביב.

**אין "רוצה לנסות" בשום מקום** — מבלבל. רק 💚.

## החלטות שנפלו בדרך
- "זה או זה" — נשאר כמו בגרסה המקורית, בלי הסבר על המשמעות שלו.
- בחירת תחביבים בשני שלבים: קודם תחומים כלליים, אחר כך פרטים רק לתחומים שנבחרו (החליף את "3 קטגוריות בכל עמוד").
- ביטול סימון של תחום מוחק גם את התחביבים שסומנו בו.
- העיר עברה ממסך "עליך" לשלב מוקדם, כדי להראות אנשים קרובים מיד.
- "+ משהו אחר" לא מופיע בבחירת הפרטים; הוספת תחביב משלי — במסך "התחביבים שלי".
